# Eddie's Wallet design system (copied source)

This directory preserves the supplied web/React design system as the visual source of truth for the native app: tokens, guidelines, components, icons, fonts, and the click-through iOS kit, copied unchanged from the original design deliverable in July 2026. It is unmaintained reference material and may not run as-is; the native SwiftUI app is the maintained implementation.

The native SwiftUI mapping is documented in [`native-swiftui-mapping.md`](native-swiftui-mapping.md). The app does not embed the web kit.
