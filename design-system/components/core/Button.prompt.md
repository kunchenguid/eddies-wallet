The main tappable action — used for parent actions like "Add deposit", "Create loan", "Continue".

```jsx
<Button variant="primary" icon={<Icon name="plus" size={18} />}>Add deposit</Button>
```

Variants: `primary` (brand green, main CTA), `secondary` (neutral fill, secondary action), `ghost` (text-only, e.g. "Not now"), `danger` (destructive, e.g. "Delete family data"). Sizes: `md` (default, 52px) and `sm` (40px, inline use).
