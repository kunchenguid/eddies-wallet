# Support

Eddie's Wallet is an unfinished development project, not a shipped consumer product. There is no App Store listing, no downloadable release, and no customer support channel. Support here means help with the source code and documentation in this repository.

## Build, source, and documentation questions

Open a public [GitHub issue](https://github.com/kunchenguid/eddies-wallet/issues) for:

- Problems following the [getting started steps](README.md#getting-started) or running the documented simulator build and tests.
- Questions about the code, the architecture boundary, or the [product requirements](docs/product-requirements.md).
- Mistakes or gaps in the documentation.

Please include your Xcode and simulator runtime versions and the exact command and output when reporting a build problem. Responses are best effort; there is no service-level commitment.

## Security and privacy reports

Do **not** use public issues for security or privacy findings, especially anything involving a child's or family's data. Use the private route described in [SECURITY.md](SECURITY.md) instead.
